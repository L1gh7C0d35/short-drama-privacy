# Limitless Short Drama — Public Privacy Policy

This repository contains **only the public privacy-policy webpage** for the original, fictional-content iOS internal beta. It intentionally does not contain the private Swift app, licensed series, tokens, signing material, personal Apple account information or actual user activity.

Published website: https://l1gh7c0d35.github.io/short-drama-privacy/

The policy applies to the current internal prototype **0.1.0**; revise it before adding external user accounts, network data collection, commercial media, payments, subscriptions, analytics or third-party SDKs. Current app privacy disclosure: **Data Not Collected**.

To report a privacy issue, open an issue without sensitive personal information.
