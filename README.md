# Limitless Short Drama — Public Privacy Policy

This repository contains the **public Privacy Policy and Help & Support pages** for the native iPhone preview with original illustrated fictional concepts and separately creator-credited open short films. It intentionally does not contain the private Swift app, licensed series, tokens, signing material, personal Apple account information or actual user activity.

Published privacy policy: https://l1gh7c0d35.github.io/short-drama-privacy/

Published support: https://l1gh7c0d35.github.io/short-drama-privacy/support.html

The public pages are updated November 12, 2026 and apply to the current internal preview **0.1.0**, including creator-credited CC open films and outward publisher links. They describe only documented current behavior; refresh these pages and the App Store privacy/age/rights declarations before any new accounts, remote data collection, commercial film licensing, payments, subscriptions, analytics or SDKs. The historical **Data Not Collected** App Store questionnaire was completed for a synthetic-only build, and needs owner verification for the newer media scope.

To report a privacy issue, open an issue without sensitive personal information.
